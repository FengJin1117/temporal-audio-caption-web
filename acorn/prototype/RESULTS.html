结论：证据不足

目前还不能有把握地回答“会”。

两个模型都检测到整体 policy 信号，时间关系题也出现方向一致的可观差异；但预注册主比较只有 +0.8 / +1.3 个百分点，没有达到 5 个百分点门槛，Holm 校正后的成对比较也不显著。

这不是 null 结论。正确解释是：信号值得扩样，但 30 个 graph 尚不能支撑论文主张。

研究决策

Go，但要定向扩样

优先增加包含多事件时间关系的音频与问题；不要简单堆叠容易达到满分的 attribute binding 题。

实验是否可信？

重点检查控制是否奏效，以及自然化是否仍满足“只改 organization”。

通过的控制

  • 同图五策略事实集合一致 通过
  • 严格层词数一致 通过
  • 双模型 prompt hash 一致 2,329 / 2,329
  • 温度与输出预算一致 0.0 / 64
  • 删除证据正控制 通过
  • 失败样本保留在分母 通过

仍需解决

  • Omni 人工听审 待完成
  • 时间关系独立 graph 仅 11
  • 自然 caption 合同通过 130 / 145
  • 自然层同图长度跨度中位数 约 19%

因此确认性结论只使用严格 clause 层；自然化层是生态观察，不能冒充纯 order 效应。

统计口径

独立单位audio graph，不把 caption 或问题当独立样本。
主比较关系题上的 chronological − seeded random。
不确定性graph-cluster bootstrap；其余比较做 Holm 校正。
失败处理abstain、malformed 与 API error 均留在总分母。
结论边界只讨论有限 decoder 的信息可访问性，不主张全局最佳顺序。
