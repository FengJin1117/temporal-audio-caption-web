Caption Prompt

Listen carefully to the provided audio and write a detailed but concise caption.

Describe all audible information that could help answer questions about the clip, including speech content, speakers, sound events, music, instruments, rhythm, mood, scene context, timing/order, and notable background sounds.

Use only evidence from the audio. Do not guess identity, age, gender, accent, location, or cultural context unless it is clearly audible from the clip.

QA Prompt Template

SYSTEM:
You are an expert in reasoning over audio captions.
Answer the question ONLY using the given caption. Do NOT infer information not explicitly stated.

If the caption is sufficient, output valid JSON exactly like {"answer": "C"}.
The answer field must contain ONLY one choice letter.

If the caption lacks information, do NOT guess. Output valid JSON exactly like {"reason": "This audio caption lacks key information about ... and is insufficient to infer the answer."}.
Output valid JSON only. No markdown or extra text outside JSON.
