两个代表样例

下面展示的是 Qwen2.5-Omni-7B baseline：同一条音频先有 teacher caption 和 reference evidence，再看 student caption 经同一 parser 后抽出的 evidence，以及单样本得分。

样例 1：主声源抓对，但细节混入错误

id: avocado_avqa_000061answer: D. frogrelation 命中

问题：What are the main sources of sound in this audio? A bird / B cricket / C Giant salamander / D frog

Teacher caption 摘要

夜间自然环境中有高音、节奏性、断续的两栖动物叫声；随后出现更低沉、喉音更重、结构更复杂的蛙叫。背景几乎安静，只有轻微高频 hiss。

Reference evidence
  • sound_event: high-pitched, rhythmic, staccato call
  • sound_event: guttural, resonant lower-pitch call
  • attribute: first call is sharp, clear, reedy, percussive
  • attribute: second call is moist, throaty, low-mid rich
  • sound_event: faint continuous high-frequency hiss

Relation: first call high-pitched/staccato vs second call lower-pitched/guttural/more complex.

QC: ok；evidence 5；relation 1；low confidence 0。

Qwen2.5 caption

The audio features a series of distinct sounds, starting with a frog croaking loudly, followed by another frog croaking in a higher pitch, then a bird chirping. The background is filled with crickets chirping.

Parsed student evidence
  • sound_event: frog croaks loudly at the beginning
  • sound_event: second frog croaks in a higher pitch
  • sound_event: bird chirps
  • sound_event: cricket chirping in the background

Relation: frog first → higher-pitched frog → bird; cricket in background.

QC: ok；evidence 4；relation 1。

Single-sample score: Evidence Recall 20.00% · Evidence Precision 25.00% · Relation Recall 100.00% · Format Pass true

讲解点：模型抓到了 frog，也构造了顺序关系，所以 relation recall 可以命中；但 bird/cricket 是额外混入，且 teacher 的声学属性细节大多没召回。

  • sound_event: intense immersive water sounds indicate high-energy environment
  • speech: Russian voice partially masked by water

Qwen2.5 caption

The audio features a man speaking in Spanish, saying “no no no ...” repeatedly; raw output continues repeating no until max token length.

Parsed student evidence
  • none

Relation: none

QC: review；flags: caption_high_repetition, json_decode:Unterminated string starting at, missing_json_object, possible_unsupported_identity_or_scene, too_few_evidence_items。

Single-sample score: Evidence Recall 0.00% · Evidence Precision 0.00% · Relation Recall 0.00% · Format Pass true

讲解点：reference 结构能表达“水声主导、语音被遮蔽、天气不可确定”；student 高重复输出让 parser 抽不出 evidence，因此该样本在 evidence 维度完全失败。

指标定义与计算方式

Evidence matching

每条 student caption 先经过同一个 text parser，得到 predicted evidence。reference evidence 来自 teacher caption 的 parser 输出。每个 evidence item 用词集合 Jaccard 相似度打分，阈值为 0.25，按分数从高到低 greedy 一对一匹配。

Evidence Recall = matched_reference_items / reference_items
Evidence Precision = matched_predicted_items / predicted_items

Relation recall

relation group 记录顺序、比较、重叠、因果、数量等跨 item 关系；同样用文本相似度匹配，阈值为 0.20。

Relation Recall = matched_reference_relation_groups / reference_relation_groups

Format pass

caption benchmark 不强制 answer tag；这里检查输出是否为非空自然语言 caption，且没有破坏性的 JSON 或不配对的 answer tag。

AVQA caption-QA

把 student caption、AVQA question 和 4 个 choices 输入文本 QA 模型，要求返回 {"answer":"A"} 或 abstain reason。score 以 100 条为分母，未回答计 0。

QA score = correct / total
Coverage = answered / total
Answered Accuracy = correct / answered
Wrong-answer Rate = wrong_answered / total

这些指标不是最终训练 reward 本身，而是用于快速判断“事件拆解 reference 是否能区分模型 caption 能力”。raw outputs、parser raw 和 QC flags 全部保留，失败样本仍在分母中。

实现方式

1. 构建样本用 load_from_disk + Audio(decode=False) 读取 AVQA，不触发音频解码；从 audio["bytes"] 导出 wav。
2. 防泄漏读取现有 held-out manifests，汇总 file_name、audio_sha256、stem 等 blacklist；命中即剔除。
3. Teacher captionQwen3-Omni Captioner 生成 100 条 raw caption；prompt 记录为 mmar_caption_simple_v1，不手改输出。
4. Evidence parser离线 text parser 只读 caption，输出 evidence_items、relation_groups 和 QC。
5. 模型评测新模型在同一 inference_manifest 上生成 caption，再复用 parser 与 scorer 计算横向指标。
